# Security and privacy

Run the server only on loopback. Never expose it through a tunnel or public port. Private prep notes are not sent to the opponent model or included in session exports. Exported public transcripts may still contain personal information.

Do not post credentials, private transcripts or audio in public issues. For a vulnerability, contact the repository owner through their GitHub profile before publishing exploit details.

macOS release builds are ad-hoc signed, not Apple Developer ID signed or notarized. Do not disable Gatekeeper globally. Review the source and the release checksum. Microphone and Speech Recognition permissions remain under your control.
