01 / PRACTICE WITH PURPOSE

More than another
argument generator.

Make space for the whole round, from the first working note to the last rebuttal.

01

Set your own room

Choose a motion, a side, and a challenge level. Work with a human partner through a six-speech round with editable timers.

02

Keep the floor yours

Prepare privately, follow the public flow, and move between speeches on your terms. Typed input is available when voice is not.

03

Review, then repeat

Correct the transcript and ask for coaching. Use the feedback as a starting point for better reasoning, not a tournament verdict.

02 / YOUR VOICE, YOUR CHOICE

Local by default.
Honest by design.

Practice is local-only by default

Reasoning runs through Ollama on your Mac. Local speech recognition requires the local helper and its model setup. Initial runtime and model downloads need internet access.

Cloud recognition is a choice, not a surprise

Optional browser / vendor recognition requires explicit opt-in and may send audio to the browser vendor for remote processing. Microphone support depends on your browser and local setup. You can always use typed practice.

A practice partner, not an authority

AI can be wrong. Verify factual claims independently. “Champion” is a difficulty label, with no guarantee of champion-level play or competitive results. This is practice, not tournament assistance.

03 / OPEN THE ROOM

Your next round
starts on your Mac.

A versioned macOS ZIP with a launcher, not a signed installer. The interface runs in your browser, while the server and model run locally.

Before you begin

Apple Silicon Mac running macOS.
Node.js 22+ installed.
Ollama installed and running with a local reasoning model.

Voice is optional and needs additional local helper setup. See the repository instructions for prerequisites and troubleshooting.

  1. Download & unzip

    Download ParliBot-macOS.zip using the button above. Unzip it to a folder on your Mac.

  2. Install the launcher

    Open the extracted folder and run Install ParliBot.command. Check the included instructions before approving any macOS prompt.

  3. Enter the practice room

    Open ~/Applications/ParliBot.app. The launcher starts the local server and opens the browser-based UI. Choose your installed Ollama model to begin.

A note about macOS security

This launch package is unsigned or ad-hoc signed and is not notarized by Apple. macOS may block it. Review the source and release instructions before opening it, and do not disable system-wide security protections.
